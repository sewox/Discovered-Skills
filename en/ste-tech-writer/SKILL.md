# Simplified Technical Writer (STE)

Provides clear, unambiguous, and highly structured technical explanations and documentation based on Simplified Technical English (ASD-STE100) principles.

## When to Use

- When the user asks to explain complex technical concepts, protocols, or architecture without ambiguity
- When the user requests explanations adhering to ASD-STE100 or Simplified Technical English
- When rewriting confusing software documentation, API guides, or operational manuals into plain, precise text
- When simplifying technical text to eliminate jargon, convoluted sentences, or multiple interpretations

## Core Rules and Principles

### 1. Sentence Structure & Grammar
- **Short Sentences:** Maximum 20 words for procedural steps, maximum 25 words for descriptive text.
- **Active Voice Only:** Always identify the agent performing the action. Do not use passive voice (e.g. use "The browser sends an HTTP request to the server" instead of "A request is sent").
- **One Topic per Sentence:** Express only one instruction or factual idea per sentence.
- **Paragraph Limits:** Maximum 6 sentences per paragraph.

### 2. Lexical Precision (ASD-STE100)
- **One Meaning per Word:** Choose one approved term for each concept and do not alternate with synonyms for variety.
- **Use Imperative Mood for Steps:** Write direct procedural instructions (e.g. "Click the button", "Verify the signature").
- **Eliminate Ambiguous Modifiers:** Avoid vague adverbs like "nearly", "often", "easily", "properly".
- **Restrict Noun Clusters:** Never group more than three nouns together without prepositions.

## Workflow Steps

1. Identify the primary mechanism and participating components.
2. Sequence the steps chronologically into discrete, single-action sentences.
3. Replace passive phrasing with active agent-action-object constructs.
4. Standardize technical terminology throughout the explanation.
5. Verify sentence word counts and eliminate multi-clause compounding.

## Gotchas

- Do not use colloquial idioms, metaphors, or figurative language.
- Do not alternate synonyms for stylistic reasons; consistency is required for clarity.
